A one-line joke entry for the make.fun bounty
[One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea).

## What it does

`main.ts` (Node) writes a single joke line to `/output/entry.txt`
as UTF-8 text with no trailing newline.

The line:

> I bought a fitness tracker so my 2 a.m. fridge trips finally count as training.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Why this line

Ten candidate lines were drafted and revised in the comments of
`main.ts`. The winner was picked against the judging brief: funny
on its own, a fast laugh, a fresh angle, tight wording, and a
small pun ("count") that rewards a re-read.
